# Trader-Sentiment-Analysis
# Bitcoin Market Sentiment vs Trader Performance Analysis

## Overview

This project analyzes the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader performance using Hyperliquid historical trading data.

## Objective

To determine whether market sentiment influences trading profitability and identify patterns that can help improve trading strategies.

## Datasets

1. Fear & Greed Index Dataset

   * Date
   * Classification (Fear, Greed, Extreme Fear, Extreme Greed, Neutral)

2. Hyperliquid Historical Trader Data

   * Account
   * Symbol
   * Execution Price
   * Size
   * Side
   * ClosedPnL
   * Leverage
   * Timestamp

## Methodology

* Data Cleaning
* Date Alignment
* Dataset Merging
* Exploratory Data Analysis
* Profitability Analysis
* Win Rate Analysis
* Sentiment-Based Performance Evaluation

## Key Findings

* Extreme Greed periods showed the highest average profitability.
* Win rates were generally higher during Greed-based market conditions.
* Fear periods demonstrated lower average profitability.
* Market sentiment appears to have a measurable impact on trader performance.
